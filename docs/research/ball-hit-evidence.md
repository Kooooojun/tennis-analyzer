# 用球找擊球：第 1 段量測（只量、不改流程）

日期 2026-11-15。問題：場上有兩個人時，擊球偵測漏很多拍，瓶頸在聲音那一步。
想法：用追球（`ball.npy`）的「球突然轉向、且靠近手腕」（`events.ball_turns()`）當第二個證據，補回聲音漏掉的拍。
只用現有的姿態、追球、聲音檔，沒有重跑姿態或追球。沒改 `tools/`。

## 結論

- 事先定的進第 2 段門檻**過了**（驗證集：漏拍有轉向 11/22 = 50% [31%, 69%]；非擊球有轉向 14/143 = 10% [6%, 16%]）。
- 但**門檻設計不夠好**：它沒有扣掉巧合。對牆影片 C 每分鐘有 59 個轉向，隨機挑一個時刻 ±6 幀碰到轉向的機率就有 18%。漏拍有轉向 56%，只是巧合的 3.1 倍。
- 離線模擬「只有球的擊球」層：對牆 C 最好 9 → 14/27，但錯報 17 → 27；手速 ≥ 6 時 9 → 12/27、錯報 17 → 19。第 2 段驗收要 ≥ 15/27 且錯報不增，做不到。
- 使用者另一場對牆練習（兩人）的 3 個清楚漏拍：0/3 有轉向，因為**球沒被追到**（±6 幀 13 格裡只有 0、0、3 格有值）。
- 所以**不做第 2 段**。真正卡住的是追球在漏拍那一刻沒有球，以及對牆 C 的轉向太多太雜。
- 以後的門檻要寫成「比巧合高多少倍」，不是只看比例。

## 六個問題（Wilson 95% 區間）

### 1. 球有沒有被追到（真擊球 ±6 幀內至少一格有值）

| 資料 | 結果 |
|---|---|
| 對牆 A | 24/25 = 96% [80%, 99%] |
| 對牆 B | 15/17 = 88% [66%, 97%] |
| 對牆 C | 27/27 = 100% [88%, 100%] |
| 網路 B | 5/5 = 100% [57%, 100%] |
| 另一場 | 62/65 = 95% [87%, 98%] |

一般擊球的球幾乎都追得到；但漏掉的那幾拍剛好沒有球（見第 3 題）。

### 2. 轉向證據：敏感度、誤報、巧合基準

| 資料 | 真擊球有轉向 | 非擊球有轉向 | 隨機時刻的巧合 | 擊球／巧合 |
|---|---|---|---|---|
| 對牆 A | 11/25 = 44% [27%, 63%] | 3/65 = 5% [2%, 13%] | 4% | 10.7× |
| 對牆 B | 2/17 = 12% [3%, 34%] | 0/29 = 0% [0%, 12%] | 0.2% | 58× |
| 對牆 C | 14/27 = 52% [34%, 69%] | 沒量（沒有非擊球真值） | 18% | 2.9× |
| 網路 B | 4/5 = 80% [38%, 96%] | 沒量 | 4% | 20× |
| 另一場 | 26/65 = 40% [29%, 52%] | 14/143 = 10% [6%, 16%]（x 3/43、聲音 11/100） | 3% | 13× |
| wall-1 候選（三支合計） | 22/50 = 44% | 1/22 = 5% | — | — |

影片是 60 fps，±6 幀＝±0.1 s。轉向數與巧合都用整支影片算（對牆 C 也是整支，不只前 60 s）。
巧合＝影片中隨機 3000 個時刻（離真擊球 > 0.5 s）±6 幀內有轉向的比例。
對牆 B 的轉向只有每分鐘 5 個，敏感度很低；對牆 C 每分鐘 59 個，敏感度高但大多是巧合。

**掃描（只用選值集：對牆 A、B、wall-1 候選；共 92 拍、116 個非擊球，A 和 wall-1 有重疊）**：

| DV_MIN | NEAR | N=3 | N=6 | N=10 | 非擊球（N=6） |
|---|---|---|---|---|---|
| 0.008 | 0.10 | 7% | 12% | 17% | 3% |
| 0.008 | 0.15（現值） | 28% | 38% | 43% | 3% |
| 0.008 | 0.20 | 34% | 47% | 57% | 8% |
| 0.004 | 0.20 | 36% | 49% | 61% | 8% |
| 0.016 | 0.15 | 22% | 32% | 37% | 3% |

`DV_MIN` 從 0.004 到 0.012 幾乎沒差；主要看 `NEAR`。放寬到 0.20 敏感度多 9 點、誤報多 5 點。N=6（現行容許）沒有一組推過 60%；只有最寬的 N=10、NEAR 0.20 才到 61%，但誤報也升到 8% 以上，且 N=10 比聲音的時間精度寬太多，所以沿用現值。

### 3. 救得回來嗎（目前 events 漏掉的真擊球裡有轉向的）

| 資料 | 結果 | 巧合 | 倍數 |
|---|---|---|---|
| 對牆 A（選值） | 1/3 | 4% | 8× |
| 對牆 C | 10/18 = 56% [34%, 75%] | 18% | 3.1× |
| 網路 B | 1/1 | 4% | 25× |
| 另一場（3 個清楚漏拍） | 0/3 | 3% | 0 |
| 驗證合計 | 11/22 = 50% [31%, 69%] | | |

**對牆 C 漏掉的 18 拍分類**（聲音 ±0.3 s 內）：

| 原因 | 個數 |
|---|---|
| 開頭 2 秒的顛球（不是正式擊球） | 4 |
| 沒有聲音 | 6 |
| 有聲音，但寬頻（bb）或手速不夠 | 8 |
| 被另一個聲音在 0.6 s 內蓋掉 | 0 |
| 其他 | 0 |

**被別人的聲音蓋掉的是 0 個**。對牆 C 的瓶頸不是「選錯聲音」，是聲音太弱或沒有，以及姿態沒抓到手速。

**另一場的 3 個清楚漏拍**：

| 漏拍 | ±6 幀內球有值的格 | 最近的轉向 | 判定 |
|---|---|---|---|
| 1 | 0/13 | +139 幀 | 球沒追到 |
| 2 | 0/13 | −24 幀 | 球沒追到 |
| 3 | 3/13 | −40 幀 | 有一點球，沒有轉向 |

### 4. 0.6 s 內有兩個以上聲音時，選哪個對

| 資料 | 這種擊球 | 最大聲對 | 剛好一個聲音有轉向：轉向那個對／最大聲對 |
|---|---|---|---|
| 對牆 A | 14 | 12 | 5/6 ／ 6/6 |
| 對牆 B | 13 | 11 | 2/2 ／ 2/2 |
| 對牆 C | 20 | 9 | 5/8 ／ 4/8 |
| 網路 B | 5 | 3 | 3/4 ／ 2/4 |
| 另一場 | 32 | 30 | 10/14 ／ 13/14 |
| 合計 | 84 | 65/84 = 77% [67%, 85%] | 25/34 ／ 27/34 |

在能比的 34 個裡，「選有轉向的那個」比「選最大聲」少對 2 個。只有對牆 C 和網路 B 多對 1 個，樣本太小。
**結論：不值得另開「選對聲音」的卡。**

### 5. 轉向格和擊球格差幾格

| 資料 | 轉向 − 真值（中位數、\|差\| p90、n） | events − 真值 |
|---|---|---|
| 對牆 A | −1、4、11 | 0、1、22 |
| 對牆 B | 0、1、2 | 0、1、17 |
| 對牆 C | 0、5、14 | −2、2、4 |
| 網路 B | 0、4、4 | −1、3、5 |
| 另一場 | 0、4、26 | （真值就是候選時間，不能比） |

轉向格的 |差| p90 是 1–5 幀，聲音減延遲是 1–3 幀（另一場的 0 是因為真值就是候選時間，不算）。n 只算 ±6 幀內配上的：對牆 C 的聲音只有 4 個、網路 B 5 個，樣本小，兩邊也都被截在 ±6 幀。**聲音大致較準**，不值得另開「用轉向格定時間」的卡。

### 6. 非擊球有轉向的來源（看標註的文字）

另一場的 x 候選 3 個：球從手上掉下碰到拍面低處、走路撿球、高球在拍頭旁沒碰到。
另一場的非擊球聲音 11 個（兩人都判 not_hit）：走路、球落地彈起在腳邊、彎腰撿球、拍子低垂沒揮。
wall-1 no_hit 1 個：球還在手上。對牆 A 休息時段 3 個。
**最多的是落地彈起與撿球、走路**（手腕在球旁邊，但沒揮）。撞牆的沒出現在誤報裡（被 `NEAR` 擋掉）。

## 選值的誠實說明

- 掃描表只用了對牆 A、B 和 wall-1 候選，沒改任何參數。
- 第 2 段的離線模擬（手速門檻 3.5／6、間隔 0.6／1.0 s）**有在驗證集上看結果**。那只是用來判斷驗收做不做得到，最好的設定也沒到驗收線；如果以後要做，得換新的驗證資料。
- wall-1 候選的真值有一部分是看追球轉向投票的，所以 wall-1 的數字偏樂觀。

## 下一步（給追球 C14）

- 卡住的是「漏拍那一刻沒有球」。建議 C14 的驗收：另一場的 3 個清楚漏拍，±6 幀內有球的格從 3/39 升到 ≥ 20/39；對牆 B 的真擊球有轉向從 12% 升到 ≥ 40%，同時對牆 C 每分鐘的轉向數不增加（現在 59，巧合 18%）。
- 可能的方法：原始解析度（不是 proxy）跑追球、或用使用者自己的對牆片重訓球模型。先試解析度，比較便宜。
- 以後任何「證據」的門檻都寫成「比巧合高 ≥ 3 倍，且下界 ≥ 2 倍」。
- 對牆 C 有 8 拍是聲音弱或手速不夠：這是姿態（兩人時手腕沒抓到）和收音的問題，不是追球能補的。
