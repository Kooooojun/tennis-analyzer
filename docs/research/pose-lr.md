# 短暫姿態左右互換修正

量測日期：2026-11-16。對應 #61 的短暫手肘／手腕互換；整身對調仍未解決，本次不關閉 issue。

## 方法與界線

`pose_full.correct_lr` 在同一人的片段合併後、低 fps 插值前處理原始影格：只修不超過 0.2 秒、兩端互換後對應距離都不到原來一半的片段。兩端的手距都須超過 0.3 軀幹長，外側左右對應須一致、至少一側關節可見度 ≥ 0.5，外側 0.2 秒內不能另有切換。缺格、人物位置大跳、整身換邊、骨段投影長度暴增或參照不足就保留原值。

手腕修正連同手指及可見度一起交換。世界座標是獨立估計，只有同一片段兩端的 3D 連續性也支持互換、且片段內沒有額外 3D 切換時才交換，避免把原本連續的 3D 翻錯。方法版本由 3 更新為 4；不改追蹤器、關聯合併、指標定義或計分。
