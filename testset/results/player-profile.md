## (c) 自動猜慣用手
真實慣用手逐張畫面確認：黑衣、白衣都是右手（白衣在 MediaPipe 左右標籤會跳，所以不能只信標籤）。

| 玩家 | 猜 | 速度比 |
|---|---|---|
| 黑衣（v1） | R ✔ | 2.91 |
| 白衣（v1 + v2 + v3 合併） | R ✔ | 1.90 |
| 白衣單支 v2 / v3 | R / R | 1.82 / 1.31 |
| 黑衣翻轉片 | L ✔ | 2.13 |
| 白衣翻轉片 | L ✔ | 1.97 |

**第一版做法失敗**：整支影片、visibility ≥ 0.5 取第 98 百分位，白衣 v1 猜成 L（比值 2.4）。原因：手持手機貼近腿時骨架亂跳，且被遮住的手腕偶爾跳得比真揮拍還快。改成：只看擊球前後窗（-24～+12 格）、速度除以軀幹長、5 格中位數濾波、可見度 ≥ 0.9。

**限制**：門檻（0.9、5 格）是在這 6 組資料上調出來的，樣本很小，換場景可能要再調；比值 < 1.15 時 assemble 會標 UNSURE；雙手反拍者、自拍鏡像影片（左右會整個反）無法判斷，只能靠使用者設定。
