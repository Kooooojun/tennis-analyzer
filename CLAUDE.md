Tennis practice analysis. For any request about tennis videos, strokes, rallies, the review page or highlights, follow `.claude/skills/tennis-analyze/SKILL.md`.

Run Python as `python tools/run.py <script>.py <session>` from the repo root (runs it with the venv's Python: `.venv/bin/python` on Mac/Linux, `.venv\Scripts\python.exe` on Windows; `python3` where there is no `python`). Videos, `work/` and `web/sessions/` are the user's private footage and stay out of git.
